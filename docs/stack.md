# Stack

## Next.js 16 (App Router) with plain JavaScript

One framework, one deploy target. Route handlers give us the first-party `/go` and `/api/hit` endpoints without a second service. The shape decision (a stateless request/response app, so one full-stack framework) follows the workspace rule.

Plain JavaScript over TypeScript is the stated preference. The gap is covered by keeping the code that shapes untyped input (request headers, the beacon body, stored events) small, isolated and tested. See `lib/analytics/`.

`AGENTS.md` is generated by `next dev` and tells contributors to read `node_modules/next/dist/docs/` first. This Next version differs from older ones: `middleware` is now `proxy`, and `params` is a promise.

Testing on a phone over Wi-Fi needs `allowedDevOrigins` in `next.config.mjs`. Next blocks dev scripts from unknown origins, so without it the page renders on the phone but nothing is interactive. It only affects `next dev` and covers the `192.168.*.*` and `10.*.*.*` ranges.

## Styling: Tailwind CSS 4

Design tokens live in `app/globals.css` under `@theme`. Anything Tailwind cannot say cleanly (text stroke, the hatch pattern, the hard shadow) is plain CSS next to the tokens.

## Fonts: `next/font/google`

Fetched at build time and self-hosted from our own domain, so a visitor's browser never talks to Google. This is the only build-time dependency on an outside service, and if it were unreachable the build would fail loudly instead of degrading silently. Three families, chosen in [design.md](design.md).

## Storage: an adapter, not a database

There is no database dependency. Production uses `ANALYTICS_STORE=remote`, which sends events to a collector on the owner's VPS rather than storing them here. See [architecture.md](architecture.md#production-storage-the-remote-store).

## Charts: none

The stats page draws bars with CSS. A chart library would be the largest dependency in the project for six bars.

## Testing: Vitest

The pure layers (`buildEvent`, `summarize`, the number-to-words headline) get real tests first. There are no component tests in v1.

## Hosting: Vercel

Static page from the CDN, functions for the two write endpoints and `/stats`. Deploy from `master` only.
